1

Install Python 3.10+

Go to python.org/downloads and download the latest Python installer.

⚠️ During installation — MUST tick:
  ✅ "Add Python to PATH" (bottom checkbox on first screen)
  ✅ "Install pip" (in optional features)

After install, verify in CMD:

python --version pip --version
2

Install Npcap Critical for ARP scan

Scapy requires Npcap to capture and send raw packets on Windows. Do NOT use old WinPcap.

  • Go to npcap.com/#download
  • Download the Npcap installer (free version is fine)
  • During installation, tick: "WinPcap API-compatible Mode"
  • Restart CMD after installing
⚠️ Install ONLY Npcap. Do NOT install WinPcap — it's outdated and will break Scapy.
3

Install Nmap Binary Required for Port Scanning

python-nmap is just a Python wrapper — it needs the actual nmap binary installed.

  • Go to nmap.org/download.html
  • Download "Latest stable release self-installer" (.exe)
  • Run installer — keep all default options
  • Nmap will auto-add itself to PATH

Verify in CMD:

nmap --version
4

Run setup.bat Installs Python Packages

After Python, Npcap, and Nmap are installed — run the included batch file:

:: In CMD (as Administrator), navigate to the project folder: cd C:\path\to\network_scanner :: Then run: setup.bat

This will automatically install scapy and python-nmap via pip and verify everything.

✅ setup.bat handles pip install, version checks, and shows you what's missing.
5

Run the Scanner

:: Always run CMD as Administrator (you already do this) cd C:\path\to\network_scanner python main.py

The GUI will open. Your local network will be auto-detected in the Target field (e.g., 192.168.1.0/24).

💡 If Npcap isn't installed yet, the scanner will automatically fall back to ping-based host discovery — port scanning with Nmap still works fine.
